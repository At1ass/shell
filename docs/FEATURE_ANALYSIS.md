## Что стоит добавить / улучшить

### Высокий приоритет

1. **Brightness виджет / OSD** — есть слайдер в дашборде, но нет виджета в баре и нет BrightnessOSD (аналогично VolumeOSD). Управление через `brightnessctl`.

2. **Bluetooth виджет** — сервис есть (`BluetoothService`), но виджета в баре нет. Должен показывать: вкл/выкл, количество подключённых устройств, иконку.

3. **VPN виджет** — сервис `VPNService` существует, виджет не реализован. Иконка щита + статус подключения.

4. **Power menu / Session actions** — нет виджета для выключения/перезагрузки/блокировки/выхода. Стандартная функциональность для shell'а.

5. **Idle Inhibitor виджет** — сервис есть, виджета нет. Кнопка "не засыпать" (иконка кофе) — особенно полезна для презентаций/видео.

### Средний приоритет

6. **Brightness Service** — нет отдельного сервиса для яркости. AudioService хорошо спроектирован и может служить шаблоном. Нужно: `brightnessctl`, привязка к глобальным горячим клавишам, IPC.

7. **Taskbar / Active Window виджет** — показывать иконку и название активного окна. Данные уже доступны через `HyprlandWindowService`.

8. **Keyboard Shortcuts OSD** — при переключении раскладки/CapsLock показывать OSD (как VolumeOSD).

9. **Больше Launcher Providers**:
   - **File search** — поиск файлов через `fd`/`find`
   - **Web search** — открыть браузер с запросом
   - **Emoji** — поиск и вставка emoji
   - **SSH/Bookmarks** — быстрое подключение к серверам

### Низкий приоритет

10. **System Tray tooltip** — tooltip для tray иконок (данные доступны через SystemTray API).

11. **Color picker** — пипетка для выбора цвета с экрана (дополнение к screenshot).

12. **Timer / Stopwatch** — виджет-таймер в баре или дашборде.

13. **Submap indicator** — показывать когда активен Hyprland submap (режим клавиш).

14. **GPU/CPU температура** — расширить SystemMonitorService для отображения температуры в баре или дашборде.

## Архитектурные заметки

### Хорошо реализовано

- Сигнальная архитектура (после рефакторинга нотификаций)
- Дизайн-система с полным набором MD3 токенов
- Динамическая тема из обоев
- Модульные виджеты бара с конфигурацией per-monitor
- IPC для внешнего управления

### Можно улучшить

- `BarWidgetLoader` использует switch/case на строках — можно сделать registry-паттерн для динамической регистрации новых виджетов
- Dashboard `QuickTab` использует GridLayout с hardcoded позициями — ригидно при добавлении элементов
- `PopoutsScrim` закомментирован в `shell.qml` — если не используется, стоит убрать или починить
